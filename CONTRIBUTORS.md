# Contributors

Thanks to everyone who has shaped SDP.

This file is maintained by hand, so that contributions which leave no commit —
design review, testing, adversarial gate review, documentation feedback — can be
credited alongside the ones that do. It is deliberately not the authoritative
list of commit authorship: for that, see the
[contributors graph](https://github.com/gonnarun/sdp/graphs/contributors), which
GitHub derives from commit metadata and nobody can edit by hand.

## Adding yourself

Open a pull request that adds your GitHub handle to the list above. There is no
minimum contribution — if you helped, say so.

To be credited on a commit you did not author yourself, add a trailer to the
commit message instead; GitHub links it to the account that owns the address:

```
Co-authored-by: Name <email@example.com>
```
